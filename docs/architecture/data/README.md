# docs/architecture/data/

Generated data files consumed by `docs/architecture/architecture-map.html` and one hand-written
supporting file — not the tool's own documentation (see `docs/architecture/README.md` for what
the tool is and how to use it).

## Files

- **`architecture-model.json`** — the full generated model `architecture-map.html` renders (every
  module, diagram, backlog summary, ADR, code-quality metric). Regenerated by
  `docs/architecture/scripts/generate-architecture-model.sh`; never hand-edited.
- **`arch-embed-index.md`** — generated index of every `<!-- #arch-embed:KEY --> ... <!-- /#arch-embed -->`
  marker found in any `CLAUDE.md`/`.claude/rules/*.md` file, keyed by marker name. Regenerated by
  the same script; never hand-edited.
- **`runtime-notes.md`** — hand-written notes on the containerized environment this project's own
  AI-assisted workflow runs in (where Claude Code executes, bind mounts, how compiling/running the
  app works from inside that container). Not generated, not about `architecture-map.html` itself.
