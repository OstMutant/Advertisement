Purpose: the result for the AI that executes it, with the detail each step's executor model needs
(exact content for a weaker model, exact files and behavior for a stronger one).

Nothing here may start before the person has taken decisions 1, 2, 6 and 7 of `plan-human.md`
(decisions 3, 4 and 5 gate single steps, named in those steps). Two paths:

- **Path F** (steps F0-F8): the Taxon category/city filter becomes a Taxon-built SQL predicate that
  Advertisement and Provider Profile splice into their own page and count statements.
- **Path A+** (keep the id set): the first pass's steps 1-6 in
  [`../pluggable-modules-opaque-refs/plan-machine.md`](../pluggable-modules-opaque-refs/plan-machine.md),
  unchanged; not repeated here.

Steps F1-F4 are one change set (the contract is replaced, not added next to the old one); run them in
order and build after F4. Measurements cited below are in [`measurements/`](measurements/).

Common rules for every step: read `/app/CLAUDE.md`, `/app/.claude/rules.md` and the
`.claude/rules/<module>.md` of every module touched before editing; `lombok.NonNull` on every
non-null public parameter; no `Optional` parameter; comments one line or none, no task or ADR
number; `git add` after each file change, never `git commit`.

### Step F1 -- The two contract types in platform-commons

- **Depends on:** F0.
- **Executor:** sonnet.
- **Files (new):** `platform-commons/src/main/java/org/ost/platform/core/model/SqlColumn.java`,
  `platform-commons/src/main/java/org/ost/platform/core/model/SqlPredicate.java`,
  `platform-commons/src/test/java/org/ost/platform/core/model/SqlColumnTest.java`,
  `platform-commons/src/test/java/org/ost/platform/core/model/SqlPredicateTest.java`.
- **Input:** `EntityRef.java` in the same package (style of a plain record), `platform-commons/pom.xml`
  (no Spring JDBC, no query-lib: keep it that way, use only the JDK and Lombok).
- **Exact behavior:**
  - `public record SqlColumn(@NonNull String alias, @NonNull String column)`: compact constructor
    rejects (IllegalArgumentException, message names the bad value) any `alias` or `column` that
    does not match `^[a-z][a-z0-9_]{0,62}$`. So an alias can never start with `_`, which is reserved
    for providers. Method `public String sql()` returns `alias + "." + column`. One-line Javadoc:
    a qualified column of the consumer's own statement that a provider's predicate correlates with.
  - `public record SqlPredicate(@NonNull String sql, @NonNull Map<String, Object> params)`:
    compact constructor copies `params` with `Map.copyOf`; rejects (IllegalArgumentException) a
    `sql` that contains `;`, `--` or `/*`; rejects any parameter name that does not match
    `^_[a-z][A-Za-z0-9]*$`; rejects a parameter name that does not occur in `sql` as `":" + name`.
    Method `public String appendTo(@NonNull Predicate<String> isBound, @NonNull BiConsumer<String, Object> bind)`:
    for each parameter, throws IllegalStateException when `isBound` is true for its name, else
    calls `bind`; returns `" AND (" + sql + ")"`. One-line Javadoc: a boolean condition built by
    the module that owns the tables it reads, spliced into another module's statement with its own
    bind values.
  - No other methods, no static factory, no `empty()` (absence is `Optional.empty()` at the Port).
- **Tests (JUnit 5, AssertJ, as `FailureRateLimiterTest` in the same module):** `SqlColumn` accepts
  `a`/`id`, `pp`/`actor_id`; rejects `A`, `_ta`, `a.id`, `a id`, `a;`, `"a"`, `a--`, empty, 64 chars.
  `SqlPredicate` rejects `;`, `--`, `/*`, a name without `_`, a name absent from the text;
  `appendTo` binds every parameter, wraps the text in parentheses after ` AND `, and throws when a
  name is already bound.
- **Verification:** `bash scripts/build-and-test.sh --unit --sandbox` green.
- **Sources:** https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html,
  https://github.com/spring-projects/spring-framework/blob/main/spring-jdbc/src/main/java/org/springframework/jdbc/core/namedparam/MapSqlParameterSource.java,
  https://github.com/spring-projects/spring-framework/blob/main/spring-jdbc/src/main/java/org/springframework/jdbc/core/namedparam/NamedParameterUtils.java

### Step F2 -- Taxon builds the predicate; the id-set contract goes

- **Depends on:** F1.
- **Executor:** sonnet.
- **Files:** `platform-commons/src/main/java/org/ost/platform/taxon/spi/TaxonPort.java`,
  `taxon-spring-boot-starter/src/main/java/org/ost/taxon/services/DefaultTaxonPort.java`,
  `taxon-spring-boot-starter/src/main/java/org/ost/taxon/services/TaxonAssignmentService.java`,
  `taxon-spring-boot-starter/src/main/java/org/ost/taxon/repository/TaxonAssignmentRepository.java`,
  `integration-tests/src/test/java/org/ost/integrationtests/level1/taxon/TaxonPortResolveCategoryAndCityFilterTest.java`
  (replaced by `TaxonCategoryAndCityPredicateTest.java` in the same package).
- **Input:** the current `findEntityIdsWithAnyTaxon`, the default `resolveCategoryAndCityFilter`
  and its private helper in `TaxonPort`; `TaxonAssignmentRepository.findEntityIdsByTaxonIds`.
  `git grep` shows no other caller of these methods outside tests.
- **Exact behavior:**
  - `TaxonPort`: remove `findEntityIdsWithAnyTaxon`, the default `resolveCategoryAndCityFilter`
    and `resolveTaxonIdFilter`; add
    `Optional<SqlPredicate> categoryAndCityPredicate(@NonNull EntityType entityType, @NonNull SqlColumn entityId, Set<Long> categoryIds, Long cityTaxonId)`
    with a one-line Javadoc: empty when neither filter is requested; a present but empty
    `categoryIds` matches nothing.
  - `TaxonAssignmentRepository`: replace `findEntityIdsByTaxonIds` by a method that builds, without
    running anything, the predicate text inline in that method:
    category part `EXISTS (SELECT 1 FROM taxon_assignment _tac WHERE _tac.entity_type = :_taxonEntityType AND _tac.entity_id = <entityId.sql()> AND _tac.taxon_id = ANY(:_taxonCategoryIds))`;
    city part the same with alias `_tay`, `_tay.taxon_id = :_taxonCityId`; the two parts joined
    with ` AND ` when both are requested. Values: `entityType.name()`, `categoryIds.toArray(new Long[0])`,
    `cityTaxonId`. Every column of `taxon_assignment` is qualified with the `_ta*` alias; no value is
    ever concatenated into the text.
  - `TaxonAssignmentService` and `DefaultTaxonPort`: pure delegation, no logic.
  - Test `TaxonCategoryAndCityPredicateTest` (Testcontainers, same base class as the test it
    replaces): the six cases of the old test (neither, only category, only city, both overlapping,
    both disjoint, category matching nothing), each executed against a consumer the test owns:
    `SELECT c.id FROM (VALUES (...)) AS c(id) WHERE TRUE` + `predicate.appendTo(params::hasValue, params::addValue)`
    with `new SqlColumn("c", "id")`; plus: the text of every predicate contains none of the ids
    passed in (values only as binds); empty `categoryIds` returns no row.
- **Verification:** `bash scripts/build-and-test.sh --unit --integration --sandbox` green after F4
  (F2-F4 do not compile apart).
- **Sources:** https://www.postgresql.org/docs/15/functions-subquery.html,

- **Depends on:** F4 and a real latency number from production data.
